# DSA by Doing
A beginner-first, Java-first data structures and algorithms learning website. Designed to run as a static GitHub Pages site.

## What works now
- Responsive landing page and six-stage learning roadmap
- Lesson 1: What is programming?
- Interactive Java `println` demonstration (simulated output, not actual Java execution)
- Knowledge check with instant feedback
- Lesson completion and browser-local progress

## Publish on GitHub Pages
1. Create a new GitHub repository, for example `DSA-by-Doing`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages** and select **Deploy from a branch**, branch **main**, folder **/(root)**.
4. Visit the GitHub Pages URL GitHub displays after deployment.

## Roadmap
Add more beginner Java lessons before unlocking the data structure and algorithm stages. For actual Java compilation and test execution, integrate a secure sandboxed backend rather than executing arbitrary Java in the browser.
