STAGE 1 · JAVA FROM SCRATCH · LESSON 1

What is programming?

Programming is giving a computer a precise set of instructions. Let's start with one instruction: asking Java to display a message.

01 / LEARN

Meet your first Java instruction

Imagine telling a friend to write a sentence on a whiteboard. In Java, we can tell the computer to print a sentence on the screen.

JAVA
System.out.println("Hello, world!");

Let's decode it: System.out.println means “print a line.” The words between quotation marks are the message. The semicolon ; ends the instruction.

You don't need to memorize the entire command today. Just recognize what it does.
